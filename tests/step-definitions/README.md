The step definitions of `@webship-js/drupal-core-steps`.

| File | Contents |
| --- | --- |
| `drupal-core.steps.js` | named pages and forms, page state, messages, content, sessions, search, contact, error pages, cache headers, listings, the rich text editor, the media library |
| `drupal-access.steps.js` | access control and the PHP error check |
| `drupal-form.steps.js` | form sections, the form time limit, AJAX, confirmation forms, editor links, the content a scenario created, taxonomy terms, menu links |
| `drupal-content-forms.steps.js` | content types, Save, required fields, content moderation |
| `drupal-site.steps.js` | modules, themes, roles and permissions, the status report, menus, the front page, the canonical URL, meta tags |
| `drupal-navigation.steps.js` | the Navigation module's sidebar and top bar |
| `drupal-layout-builder.steps.js` | Layout Builder |
| `drupal-users.steps.js` | optional: creating and removing the accounts of the users registry |
| `drupal-helpers.js` | not a step file: the helpers the steps share, which other Drupal step packs require |
| `drupal-defaults.js` | not a step file: the hooks that load the selector preset and the assets folder |
